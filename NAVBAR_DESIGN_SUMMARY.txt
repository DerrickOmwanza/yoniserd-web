   4. Body scroll is locked (prevents background scroll)

   1. User taps "About Us" (with dropdown arrow)

   3. Sub-items slide down (smooth animation)
   4. Item hover: Background turns green (Accent Green 20%)

   NAVIGATE:
   1. User taps menu item (e.g., "Gallery")
   2. Menu closes automatically
   3. Page navigates to gallery
   4. Smooth transition (professional UX)
   
   CLOSE MENU:
   Three ways to close:
   1. Tap "×" close button (top right)
   2. Click semi-transparent backdrop
   3. Select a navigation item (auto-closes)
