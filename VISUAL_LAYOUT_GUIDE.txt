================================================================================
                        COLOR REFERENCE
================================================================================

BACKGROUND & GRADIENTS:
  Deep Forest     #102C26    Primary background, headings, navbar
  Champagne       #F7E7CE    Gradient accent, warm tones
  Gradient        #102C26 → #1a3d34 → #F7E7CE (135° angle)

INTERACTIVE ELEMENTS:
  Emerald Green   #2E7D32    Buttons, accents, highlights
  Muted Forest    #145C44    Hover states, darker green

TEXT & CONTRAST:
  White           #FFFFFF    Primary text (11.5:1 contrast on dark)
  Transparent     rgba(255,255,255,0.95)  Sub-text, soft white

OVERLAYS:
  Dark overlay    rgba(16, 44, 38, 0.85)  Caption background
  Image overlay   135° gradient with opacity


================================================================================
                        BUTTON STATES
================================================================================

NORMAL STATE:
┌────────────────────┐
│  Get Involved  →   │
└────────────────────┘
Background: Emerald Green (#2E7D32)
Text: White
Shadow: 0 4px 12px rgba(46, 125, 50, 0.3)


HOVER STATE:
┌────────────────────┐
│  Get Involved  →   │ ← Lifted 2px (transform: translateY(-2px))
└────────────────────┘
Background: Muted Forest (#145C44)
Shadow: 0 6px 20px rgba(20, 92, 68, 0.4) (stronger)
Arrow: Slides right 4px


FOCUS STATE (Keyboard):
┌┆──────────────────┆┐
│  Get Involved  →   │
└┆──────────────────┆┘
Outline: 3px solid #7EBBBFF (blue)
Outline offset: 2px


ACTIVE STATE (Click):
┌────────────────────┐
│  Get Involved  →   │
└────────────────────┘
Returns to normal position
No elevation effect

================================================================================
                        SHADOW & DEPTH
================================================================================

IMAGE CONTAINER:
  Box shadow: 0 20px 40px rgba(0, 0, 0, 0.3)
  Adds depth and separation from background

BUTTON NORMAL:
  Box shadow: 0 4px 12px rgba(46, 125, 50, 0.3)
  Subtle lift effect

BUTTON HOVER:
  Box shadow: 0 6px 20px rgba(20, 92, 68, 0.4)
  Enhanced elevation effect

PARTNER LOGO HOVER:
  Box shadow: 0 4px 12px rgba(46, 125, 50, 0.2)
  Subtle interactive feedback


================================================================================
                        ANIMATIONS
================================================================================

IMAGE FADE-IN:
  Duration:  0.6 seconds
  Easing:    ease-in-out
  Property:  opacity (0 → 1)
  Result:    Smooth appearance on page load

BUTTON HOVER:
  Duration:  0.3 seconds
  Easing:    cubic-bezier(0.4, 0, 0.2, 1)
  Effects:   - Color change (#2E7D32 → #145C44)
             - Elevation translateY(-2px)
             - Shadow increase

ARROW ANIMATION:
  Duration:  0.3 seconds
  Effect:    Arrow slides right +4px on button hover

PARTNER LOGO HOVER:
  Duration:  0.3 seconds
  Effects:   - Scale: 1 → 1.05 (5% larger)
             - Background fade
             - Border glow


================================================================================
                        ACCESSIBILITY FEATURES
================================================================================

FOCUS INDICATORS:
  Width:        3px
  Color:        #7EBBBFF (Friendly blue)
  Outline:      solid
  Offset:       2px
  Visible on:   Button, partner logos, all interactive elements

CONTRAST RATIOS:
  White on Deep Forest:    11.5:1 (AAA - exceeds AA)
  Green on Dark:           5.2:1  (AA+)
  All text meets AA+ minimum standard (4.5:1)

KEYBOARD NAVIGATION:
  Tab:   Cycles through interactive elements (button, logos)
  Enter: Activates links/buttons
  Focus: Always visible with blue outline

REDUCED MOTION:
  On prefers-reduced-motion: reduce
  All animations disabled
  No transitions
  Instant state changes


================================================================================
                        RESPONSIVE BREAKPOINTS
================================================================================

DESKTOP:   ≥ 769px
  Layout:  50/50 grid (side-by-side)
  Heading: 3rem
  Image:   500px height
  Logos:   4-column grid

TABLET:    641px - 768px
  Layout:  Transitional (50/50 → stacked)
  Heading: 2rem
  Image:   400px height
  Logos:   3-column grid

MOBILE:    481px - 640px
  Layout:  100% stacked (text above image)
  Heading: 1.5rem
  Image:   350px height
  Logos:   2-column grid

SMALL MOBILE: ≤ 480px
  Layout:  100% stacked
  Heading: 1.5rem
  Image:   280px height
  Logos:   1-2 column responsive
