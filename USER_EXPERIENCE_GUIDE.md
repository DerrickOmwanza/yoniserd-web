# User Experience Guide - Dark Theme Feature
**How Users Will Interact with the New Theme Toggle**

---

## 🎯 What Users See

### First Time Visiting
User opens **yoniserd.co.ke** in their browser.

**Desktop**: 
- Site loads with default theme (white background, dark text)
- Top right of navbar: 3 small icons (☀️ ⚙️ 🌙)

**Mobile**:
- Site loads with default theme
- Hamburger menu visible (three lines icon)
- No theme buttons visible yet

---

## 📱 Desktop User Experience

### Step 1: Discover the Theme Toggle
```
┌─────────────────────────────────────────────────────┐
│ [LOGO] About    What We Do    Gallery   News        │
│                              ☀️ ⚙️ 🌙 Contact      │
└─────────────────────────────────────────────────────┘
                        ↑ Theme buttons
```

User notices **3 icon buttons** on the right side of the navigation bar:
- **☀️** - Light Theme (for daytime)
- **⚙️** - Default Theme (original design)
- **🌙** - Dark Theme (for night viewing)

### Step 2: Hover Over Button
User hovers their mouse over the **🌙** (dark theme) button.

**What happens:**
- Button grows slightly larger (1.1x scale)
- Glowing green highlight appears around button
- Cursor changes to pointer (indicates clickable)
- Feedback: "This is interactive!"

### Step 3: Click Dark Theme
User clicks the **🌙** button.

**What happens immediately:**
- Button compresses briefly (visual feedback)
- Button shows bright green highlight (active state)
- Website colors transition smoothly (300ms fade)

**Color changes:**
- Background: White → Deep Charcoal (#121212)
- Text: Dark → Light Gray (#E0E0E0)
- Accents: Green highlights become brighter

**Result:**
- Entire page now has dark background
- Text is light colored (easy to read on dark)
- Perfect for evening/night browsing
- Eyes feel more comfortable

### Step 4: Browse in Dark Mode
User navigates the site normally.

**Everything works the same:**
- All links clickable
- All pages accessible
- Dark theme applies everywhere
- Images load normally
- Videos play normally

### Step 5: Try Light Theme
User clicks the **☀️** (light theme) button.

**What happens:**
- Colors fade smoothly again (300ms)
- Background: Charcoal → Soft Gray (#F9FAFB)
- Text: Light → Dark (#102C26)
- Button shows active state (green)

**Result:**
- Softer, slightly gray background
- Professional, easy-on-eyes appearance
- Great for bright environments

### Step 6: Return to Default
User clicks **⚙️** (default/settings) button.

**What happens:**
- Colors transition smoothly (300ms)
- Background: Soft Gray → Pure White (#FFFFFF)
- Text: Dark → Dark (same)
- Button shows active state

**Result:**
- Original design restored
- Classic look with pure white background
- Still readable and professional

### Step 7: Refresh Page
User refreshes the page (F5 or Ctrl+R).

**What happens:**
- Theme persists!
- Same theme they selected is still active
- No need to reselect
- Browser remembered their preference

**User thinks:** "Nice! It remembers my choice."

## 📊 What Happens Behind the Scenes

### When User Clicks a Theme Button

```
User clicks 🌙
    ↓
JavaScript detects click
    ↓
React state updates: theme = "dark"
    ↓
document.documentElement.setAttribute('data-theme', 'dark')
    ↓
CSS [data-theme="dark"] rules activate
    ↓
CSS variables update:
  --theme-bg-primary: #121212
  --theme-text-primary: #E0E0E0
  --theme-accent-green: #2ECC71
    ↓
All elements with transitions smoothly change colors (300ms)
    ↓
localStorage.setItem('app-theme', 'dark')
    ↓
Preference saved in browser
    ↓
User sees smooth color fade
```

**Total time:** Instant to perception (300ms transition)

## 🔒 User Privacy & Data

### What Gets Saved?
- **Only:** User's theme preference ('light', 'dark', or 'default')
- **Storage:** Browser's localStorage (on their device only)
- **No tracking:** Not sent to any server
- **No analytics:** Not used to track user behavior
- **No cookies:** Uses web storage, not cookies

### When Gets Saved?
- **Immediately:** When user clicks a theme button
- **Persisted:** Until user clears browser data
- **Permanent:** Until user manually changes theme

### User Control
- User can clear at any time: DevTools → Storage → Clear
- User can change theme any time: Just click another button
- User can delete manually: Ctrl+Shift+Delete → Clear localStorage
