## 📋 Quick Reference

### Component Props
```jsx
<AboutHeroSection 
  images={Array}              // Required: array of image paths
  captions={Array}            // Required: array of caption strings
  containerHeight={String}    // Optional: Tailwind height class
/>
```

### Default Behavior
- Auto-play: 6 seconds per slide
- Navigation: Arrows, dots, counter
- Animations: Smooth fades (700ms)
- Responsive: Mobile → Tablet → Desktop
- Accessible: WCAG 2.1 AA compliant

### Key Features
✅ Auto-playing slideshow
✅ Manual navigation (arrows + dots)
✅ Image captions with overlay
✅ Slide counter (e.g., "1 / 3")
✅ Auto-play indicator
✅ Two CTA buttons (primary + secondary)
✅ Smooth animations
✅ Fully responsive
✅ Keyboard accessible
✅ Screen reader optimized
