  Duration: 300ms
  Easing: cubic-bezier(0.4, 0, 0.2, 1) - ease-out
  Animation: transform translateX(100%) → translateX(0)
  
BACKGROUND COLORS (Hover):
  Duration: 300ms
  Easing: ease
  Property: background-color
  
CHECKBOX ROTATION (Dropdown Expand):
  Duration: 300ms
  Easing: ease
  Transform: rotate(0deg) → rotate(180deg)
  
PADDING SHIFT (Sub-items Hover):
  Duration: 300ms
  Easing: ease
  Transform: padding-left 1.5rem → 1.75rem
  
BUTTON SCALE (Contact Button Hover):
  Duration: 300ms
  Easing: ease
  Transform: scale(1.0) → scale(1.02)
  
ICON SCALE (Hamburger Click):
  Duration: Instant
  Transform: scale(1.0) → scale(0.95)
  
ICON ROTATION (Close Button Hover):
  Duration: 300ms
  Easing: ease
  Transform: rotate(0deg) → rotate(90deg)

  • Enter: Activate buttons, expand dropdowns
  • Escape: Close menu (if implemented)
  
FOCUS INDICATORS:
  • Color: Accent Green (#2E7D32) 2px outline
  • Offset: -2px inset (for clean appearance)
  • All buttons: Have visible focus ring
  • Ensures keyboard users know where they are
  
ARIA LABELS:
  • aria-label="Toggle navigation menu" - hamburger button
  • aria-label="Close navigation menu" - close button
  • aria-expanded="true|false" - menu state
  • aria-controls="mobile-menu" - button controls menu
  • role="dialog" - menu semantically a dialog
  • aria-modal="true" - menu is modal
  
SCREEN READER:
  • Menu announced as "Mobile navigation menu"
  • Button states announced (open/closed)
  • Links are properly associated with descriptions
  • Semantic HTML structure helps navigation

  • Minimum: 48×48px (WCAG 2.5.5)
  • Hamburger: 7×7 icon inside 48×48 button
  • Close button: 48×48px exactly
  • Menu items: 56px tall (comfortable)
