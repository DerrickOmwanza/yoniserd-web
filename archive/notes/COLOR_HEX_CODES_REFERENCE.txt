LIGHT BACKGROUND COLORS (Premium Whites)
================================================================================

1. GLISTENING WHITE
   Hex Code: #F4F4EC
   RGB: 244, 244, 236
   Usage: Primary page background, default sections
   Effect: Warm, inviting, reduces eye strain
   CSS Variable: var(--ng-bg-primary)

2. CAKE BATTER
   Hex Code: #F0EDDB
   RGB: 240, 237, 219
   Usage: Warm accent backgrounds, hover states, CTAs
   Effect: Cream-like warmth, professional elegance
   CSS Variable: var(--ng-bg-warm)

3. BRILLIANT WHITE
   Hex Code: #EDF1FE
   RGB: 237, 241, 254
   Usage: Cool-toned accent backgrounds, card backgrounds
   Effect: Fresh, contemporary feel, professional light
   CSS Variable: var(--ng-bg-cool)

4. HALF BLACK WHITE
   Hex Code: #F0EEEA
   RGB: 240, 238, 234
   Usage: Neutral accent, secondary backgrounds
   Effect: Balance between warm and cool, subtle transition
   CSS Variable: var(--ng-bg-neutral)

5. METALLIC WHITE
   Hex Code: #FBFCF6
   RGB: 251, 252, 246
   Usage: Pure light accents, text on dark backgrounds, light borders
   Effect: Crisp, clean, minimal, maximum contrast
   CSS Variable: var(--ng-bg-pure)

DARK TEXT & OVERLAY COLORS (Professional Blacks/Grays)
================================================================================

1. MIDNIGHT MIST
   Hex Code: #000000
   RGB: 0, 0, 0
   Usage: Pure black text, emergency maximum contrast
   Effect: Maximum contrast, highest readability (21:1 on white)
   CSS Variable: var(--ng-text-dark)

2. SILVER SLATE
   Hex Code: #8C8889
   RGB: 140, 136, 137
   Usage: Secondary/medium gray text, subtle borders, muted elements
   Effect: Soft yet professional, comfortable reading
   CSS Variable: var(--ng-text-gray-1)

3. CLOUDED PEARL
   Hex Code: #CFCFD3
   RGB: 207, 207, 211
   Usage: Light gray, borders, dividers, tertiary text on dark backgrounds
   Effect: Subtle, sophisticated, professional divider color
   CSS Variable: var(--ng-text-gray-2)

4. SMOKY BLACK
   Hex Code: #111200
   RGB: 17, 18, 0
   Usage: Primary dark text, navigation backgrounds, main headings, deep accents
   Effect: Professional, warm-toned black, feels less harsh than pure black
   CSS Variable: var(--ng-text-deep)

5. OLIVE DRAB
   Hex Code: #565449
   RGB: 86, 84, 73
   Usage: Earth-tone accents, secondary text, buttons, borders, body text
   Effect: Natural, grounded, professional, warm, readable
   CSS Variable: var(--ng-text-gray-3) or var(--accent-dark)
