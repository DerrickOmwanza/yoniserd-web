PRIMARY PALETTE (4 Roles)
───────────────────────────────────────────────────────────────────────────────

  1. PRIMARY: #102C26 (Deep Forest)
     → Headers, navigation, body text, brand identity
     → Contrast: 11.9:1 on white ✅ AAA

  2. SECONDARY: #F7E7CE (Champagne)
     → Section highlights, warm accents, secondary backgrounds
     → Contrast: 8.5:1 on dark ✅ AAA

  3. ACCENT: #2E7D32 (Emerald Green) — NEW!
     → Primary CTAs, buttons, links, focus rings
     → Contrast: 5.8:1 on white ✅ AAA

  4. NEUTRALS:
     - Dark:       #1a1a1a (Near black - overlays, dark text)
     - Gray:       #6B6B6B (Secondary text, muted UI)
     - Light:      #F5F5F5 (Subtle backgrounds)
     - White:      #FFFFFF (Main backgrounds)

DO's & DON'Ts
───────────────────────────────────────────────────────────────────────────────

  ✅ DO
    • Use PRIMARY for all headings and body text
    • Use ACCENT for all primary CTAs and important links
    • Use SECONDARY for background sections to add warmth
    • Pair color with icons/text for status (✓, ✗, ⚠)
    • Test contrast with WebAIM before shipping
    • Use focus:ring-brand-accent for keyboard navigation

  ❌ DON'T
    • Use SECONDARY as text color on white backgrounds
    • Mix multiple accent colors on one page
    • Use color alone to indicate status
    • Create new colors; use the 4 core roles
    • Assume palette is complete; ask design before adding colors

QUICK DECISION TREE
───────────────────────────────────────────────────────────────────────────────

  "What color should this element be?"

  Is it a heading or main content?
    → PRIMARY (#102C26)

  Is it a button or CTA?
    → ACCENT (#2E7D32)

  Is it a section background or highlight?
    → SECONDARY (#F7E7CE)

  Is it secondary or muted text?
    → GRAY (#6B6B6B)

  Is it a dark section or footer?
    → DARK (#1a1a1a)

  Is it text on dark?
    → WHITE (#FFFFFF)

  Unsure?
    → Use PRIMARY as fallback. It's the safest.
