 USER FLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. USER VISITS SITE
   ↓
2. ThemeProvider loads theme from localStorage
   ├─ If saved: applies saved theme (default: 'default')
   └─ If new user: applies 'default' theme
   ↓
3. Page renders with selected theme colors
   ↓
4. USER SEES THEME TOGGLE BUTTONS
   ├─ Desktop: Right side of navbar
   └─ Mobile: Inside hamburger menu
   ↓
5. USER CLICKS 🌙 (DARK THEME)
   ├─ React state updates
   ├─ document.documentElement.setAttribute('data-theme', 'dark')
   ├─ CSS variables change values
   ├─ Colors fade smoothly (300ms)
   └─ localStorage saves preference
   ↓
6. PAGE REFRESHES
   ├─ ThemeProvider reads localStorage
   ├─ Dark theme loads immediately
   └─ User preference preserved!
