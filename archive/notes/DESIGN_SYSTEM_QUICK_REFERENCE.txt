================================================================================
                          IMPLEMENTATION STEPS
================================================================================

1. IMPORT DESIGN SYSTEM
   Add to src/index.css:
   @import './styles/HomepageDesignSystem.css';

2. APPLY CLASSES TO SECTIONS
   Each section follows pattern:
   - Wrapper: .section-padded .section-bg-[color]
   - Heading: .section-title
   - Layout: .split-container or .card-grid-3
   - Cards: .card or .story-card
   - Buttons: .btn-primary or .btn-secondary

3. TEST RESPONSIVE
   Desktop (1200px): 3-column grids, 50/50 splits
   Tablet (768px): 2-column grids, stacked splits
   Mobile (480px): 1-column, full-width buttons

4. VERIFY COLORS
   ✓ Backgrounds alternate (Champagne ↔ White)
   ✓ Headings dark forest
   ✓ Buttons primary or secondary (not custom)
   ✓ All text readable (WCAG AA+ contrast)

5. CHECK ACCESSIBILITY
   ✓ Focus outline visible (blue on Tab)
   ✓ All buttons keyboard accessible
   ✓ Alt text on images
   ✓ Heading hierarchy correct (H1 → H2 → H3)

================================================================================
                        ACCESSIBILITY FEATURES
================================================================================

✓ Color Contrast:
  - White text on Deep Forest: 11.5:1 (AAA)
  - Bright Green on white: 5.2:1 (AA+)
  - All text meets WCAG AA minimum: 4.5:1

✓ Focus States:
  - All buttons: 3px blue outline (#7EBBBFF)
  - Outline offset: 2px
  - Visible on keyboard Tab

✓ Responsive:
  - Mobile-first design
  - Flexible grid system
  - Touch targets ≥48px
  - Readable at 200% zoom

✓ Semantic HTML:
  - Proper heading hierarchy (H1 → H2 → H3)
  - Meaningful alt text
  - Button/Link semantics
  - Proper form labels

✓ Reduced Motion:
  - All animations disabled
  - Transitions removed
  - Instant state changes
  - Respects prefers-reduced-motion
