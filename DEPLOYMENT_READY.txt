STEP 1: UPLOAD TO TRUEHOST (2 minutes)
─────────────────────────────────────────

1. Open Truehost File Manager or FTP client
2. Navigate to: public_html/
3. Delete old files:
   - index.html
   - static/ folder
4. Upload from: c:/Users/ADMIN/ynis-rd-website/build/
5. Upload the ENTIRE contents to public_html/
   
✓ Verify: index.html exists in public_html/ (not in subfolder)
✓ Verify: static/css/ folder exists with CSS files
✓ Verify: static/js/ folder exists with JavaScript files


STEP 2: CLEAR CACHE (1 minute)
─────────────────────────────────────────

1. Browser Cache:
   • Chrome/Edge: Ctrl+Shift+Delete
   • Safari: Preferences → Privacy → Remove All Website Data
   • Firefox: History → Clear Recent History

2. OR use Incognito Window:
   • Chrome/Edge: Ctrl+Shift+N
   • Safari: File → New Private Window
   • Firefox: Ctrl+Shift+P

3. Close and reopen browser


STEP 3: TEST ON MOBILE (2 minutes)
─────────────────────────────────────────

1. Open: yoniserd.co.ke on mobile phone
   OR use Chrome DevTools (F12) device emulation

2. Test Hamburger Menu:
   ✓ Icon is WHITE and VISIBLE
   ✓ Clicking opens menu smoothly
   ✓ Menu slides in from right
   ✓ Dark green background
   ✓ Closing button (X) works
   
3. Test Mobile Layout:
   ✓ Spacing is compact (no wasted space)
   ✓ Text is readable
   ✓ Images display properly
   
4. Test Impact Section:
   ✓ Background is dark green
   ✓ Numbers visible and readable
   
5. Test Principles Cards:
   ✓ All card names visible
   ✓ No text truncation

That's it! ✅
